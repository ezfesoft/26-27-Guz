| Kısayol Tuşu | İşlev |
| :--- | :--- |
| **`➡️` / `Space` / `PageDown`** | **Sonraki Slayt** |
| **`⬅️` / `PageUp`** | **Önceki Slayt** |
| **`Home` / `End`** | **İlk / Son Slayta Git** |
| **`F`** | **Tam Ekran (Fullscreen) Aç / Kapat** |
